# Data-source research and local Android coverage

Provider catalogs and terms can change. For Android local mode, the OpenLigaDB catalogue and OpenFootball's football.json file tree determine currently available competitions and imported data. StatsBomb is included only as a separate fixed historical sample, not as a source of upcoming fixtures.

| Source | Access and coverage | Data fields | Rights and decision |
|---|---|---|---|
| [OpenLigaDB](https://www.openligadb.de/) | Used by Android local mode. Public API, no API key. Available leagues/seasons are discovered from the live catalog. Community-maintained coverage varies and is not complete for Europe. The app paces requests, retries transient failures, and consults the last-change endpoint before downloading unchanged schedules. | Match IDs, dates/times, home/away teams, matchday, and available results. Halftime results and venues may be present. Date/time changes are detected using stable fixture IDs. The provider does not reliably expose cancellation status, xG, odds, or exhaustive historical statistics. | [ODbL 1.0](https://www.openligadb.de/lizenz); attribution and database obligations may apply. Android displays the source and stores only data returned by the API. |
| [OpenFootball football.json](https://github.com/openfootball/football.json) | Used by Android local mode. The APK bundles a historical snapshot pinned to revision `e6744429ee395bc86f247348c6184bb08d4eb361`: 262 season files, 31 competition codes, 88,628 source rows, 12 exact duplicate rows deduplicated during import, 88,616 unique fixtures, and 83,536 rows with final scores. The source dates range from 2010-07-12 to 2027-05-30. Its manifest records each Git blob SHA and coverage statistic. Later synchronization discovers the current repository tree and fetches changed/new files directly from raw.githubusercontent.com. The README says the latest season files are regenerated daily from Football.TXT sources; those upstream source files are contributor-maintained and not guaranteed to update daily. | Match date, optional time, home/away team names, round, full-time and sometimes halftime scores; venue may be absent. The source does not reliably provide a time zone, match statistics, xG, odds, injuries, or lineups. | The pinned repository README identifies the generated dataset as public domain/CC0. Android records the Git object revision for each imported file and keeps source attribution. |
| [StatsBomb Open Data](https://github.com/statsbomb/open-data) | Bundled offline as a separate, fixed sample of 34 selected 1. Bundesliga matches from 2023/2024, pinned to revision `4b73468fc5b0f1950f9f66fada70ad3a4f9327cb`. This is not a complete season and is not polled for live updates. | Event-derived xG totals and shot counts, plus lineup-file cards and match lineups. It does not supply injury reports or a match possession percentage in this compact dataset. These statistics are not used by upcoming predictions because the sample is sparse. | StatsBomb states that its free open data is for research projects and football analytics, and asks users publishing/sharing analysis to credit StatsBomb and use its logo. The app credits the source; check current terms and include the official media-pack logo before redistributing analyses. |
| [football-data.co.uk](https://www.football-data.co.uk/) | The site advertises 32 seasons of results and 27 seasons of odds/statistics for selected European leagues; the exact competition/field coverage varies by season. | Results, halftime scores, selected shots/cards/corners, and bookmaker odds where supplied; no guaranteed xG or lineup/injury history. | Not imported. Its terms restrict automated bot/scraper access and AI-training products, so its historical depth does not make it suitable for this automated pipeline. |
| [football-data.org](https://www.football-data.org/pricing) | API registration is available, but the reviewed public pricing page lists paid plans starting at €29/month for the required service; a free registration is not equivalent to free access to the required historical/current data. | API-specific league and fixture data vary by subscription. | Not selected because the needed service is not available on a suitable free tier. |
| Other GitHub/open datasets | Individual repositories may publish useful results, but the league coverage, update cadence, provenance, and redistribution/model-training rights differ. | Frequently results-only; statistics and time zones can be incomplete. | Not automatically ingested unless the repository has a documented source and compatible license. No undocumented scraping or license inference. |

## Android local-mode coverage limits

- OpenLigaDB discovers only competitions currently exposed by its catalog; unavailable leagues are not represented as covered.
- The bundled history is a pinned, finite selection of European season JSON files. The Android app also imports only football.json files that exist in its current repository tree. Other OpenFootball country-repository Football.TXT files are not imported by the app.
- Parsed values are stored only when present. A missing kickoff, halftime score, or final score stays null. OpenFootball event lines and player-level data are not imported by the Android client.
- The app imports the bundled archive offline on first use and checkpoints files for safe resumption. Later live synchronization imports at most 20 due OpenLigaDB seasons and 20 changed/new OpenFootball files per run.
- Where an explicit OpenFootball-to-OpenLigaDB competition/season mapping exists, the app keeps the already stored provider as the source of record; it does not heuristically merge separate provider fixture IDs.
- The app schedules local WorkManager synchronization every 12 hours when network constraints are met. Android can defer this work; it is not an always-on server-side job.
- Historical OpenLigaDB seasons are checked monthly; failures remain in local sync metadata and can be retried. Current/recent seasons are checked every 15 minutes while synchronization is requested.
- StatsBomb's bundled sample is stored independently from fixture sources to avoid false ID/team matching. It does not add forthcoming matches or alter prediction inputs.
